## PR diffs

```zsh
# make gh page its output like git does
gh config set pager less
```

```zsh
# Everything in one diff (#1 + #2 + #4)
gh pr list
gh pr diff 4
gh pr diff 4 --color always | less -R
# same diff, and git pages it on its own:
git diff main...origin/feat/yes-path
```

- 3 dots = "waht the branch changed since it split off from main"
- 2 dots = also compare against main's commits

```zsh
# One PR at a time: each PR is exactly one commit, so:
git show origin/fix/seams       # #1
git show origin/feat/nice-ice   # just #2's change
git show origin/feat/yes-path   # just #4's change
# or all three in order, oldest first:
git log -p --reverse main..origin/feat/yes-path
gh pr diff 2 won't do this. Its base is main too, so it shows #1 + #2 together.
```

## Worktrees (one repo, two folders)

- worktree = second folder with another branch checked out
	- shares the same .git
	- (not a clone)

- use it when:
	- the devlog is live on main and a PR needs editing at the same time
	- a branch can only be checked out in one folder at a time

- create:
```zsh
# from ~/repos/Hello_Eliza, on main
git worktree add ../Hello_Eliza-pr5 docs/cave-design   # ../ = next to this folder, in ~/repos
git worktree list                                      # see both folders
# edit, commit, push the PR from ~/repos/Hello_Eliza-pr5
# after the PR merges, from ~/repos/Hello_Eliza:
git worktree remove ../Hello_Eliza-pr5
```

- clone = its own .git, syncs by push/pull
- worktree = one .git, so a commit shows up in both folders right away
- the worktree's .git is a tiny file pointing back to the real one

- Edit:
	- File → Add Folder to Workspace…  # VS Code, connected to the mini
	- type ~/repos/Hello_Eliza-pr5, OK
	- edit under Hello_Eliza-pr5/docs/cave/ in the Explorer tree
	- commit and push from the tmux window  # ~/repos/Hello_Eliza-pr5

## Undoing local edits

```zsh
git stash          # undo edits, keep a copy
git stash show -p  # see what's in the copy
git stash drop     # throw the copy away
git restore .      # undo edits, no copy
```

- git restore . only covers the folder you're in, so run it from the repo root
- checkout refuses to switch branches if an edited file is different on the other branch
