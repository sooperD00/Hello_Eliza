## PR diffs

```zsh
# make gh page its output like git does
gh config set pager less
```

```zsh
# Everything in one diff (#1 + #2 + #4)
gh pr diff 4
gh pr diff 4 --color always | less -R
# same diff, and git pages it on its own:
git diff main...origin/feat/yes-path
```

- 3 dots = "waht the branch changed since it split off from main"
- 2 dots = also compare against main's commits

```zsh
# One PR at a time: each PR is exactly one commit, so:
git show origin/fix/seams       # #1
git show origin/feat/nice-ice   # just #2's change
git show origin/feat/yes-path   # just #4's change
# or all three in order, oldest first:
git log -p --reverse main..origin/feat/yes-path
gh pr diff 2 won't do this. Its base is main too, so it shows #1 + #2 together.
```
